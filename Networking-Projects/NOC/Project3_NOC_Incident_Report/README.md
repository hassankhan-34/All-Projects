# NOC Monitoring & Incident Response Lab Using Zabbix

## 📌 Overview

This project demonstrates a complete Network Operations Center (NOC) monitoring environment using Zabbix and EVE-NG. The lab monitors Cisco network devices using ICMP and SNMP while simulating real-world incident detection, investigation, root cause analysis, resolution, and verification.

---

## 🛠 Technologies Used

- Zabbix
- Kali Linux
- EVE-NG
- Cisco IOS
- SNMP
- ICMP

---

## 🌐 Lab Topology

The monitoring environment consists of:

- Kali Linux (Zabbix Server)
- ISP Router (ISP-R1)
- Home Router (Home-R1)
- Layer 2 Switch (SW1)
- Three Client PCs

---

## ⚙ Features

- Zabbix Server Configuration
- Device Monitoring

- SNMP Monitoring
- Trigger Configuration
- Alert Generation
- Incident Response Workflow
- Root Cause Analysis

- Professional Incident Documentation

## 🚨 Simulated Incident

A controlled outage was created by shutting down the Home-R1 router.

The project demonstrates:

- Problem Detection
- Alert Generation
- Investigation
- Root Cause Analysis
- Resolution
- Verification
- Incident Closure
