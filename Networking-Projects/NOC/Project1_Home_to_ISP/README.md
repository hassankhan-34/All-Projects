# Home Network to ISP to Internet

## 📌 Overview

This project simulates a real-world home network connected to the Internet through an Internet Service Provider (ISP). It demonstrates Layer 2 switching, Layer 3 routing, DHCP, NAT, Serial WAN connectivity, and end-to-end Internet access using Cisco IOS in EVE-NG.

The project also maps network communication to the OSI Model and verifies connectivity using real network tests.

---

## 🛠 Technologies Used

- Cisco IOS
- EVE-NG Community Edition
- NAT (Network Address Translation)
- DHCP
- Layer 2 Switching
- Serial WAN
- ICMP
- DNS

---

## 🌐 Network Topology

- Cloud0 (Internet)
- ISP Router (ISP-R1)
- Home Router (Home-R1)
- Layer 2 Switch (SW1)
- Three Windows XP Clients (PC1–PC3)

---

## ⚙ Features

- Home LAN configuration
- DHCP Server
- Double NAT implementation
- Serial WAN connectivity
- Internet access through ISP
- DNS resolution
- OSI Layer mapping
- End-to-end connectivity testing

---

## 🧪 Connectivity Tests

The following tests were successfully verified:

- Ping Default Gateway
- Ping ISP Router
- Ping Public IP (8.8.8.8)
- DNS Lookup
- Internet Reachability by Hostname
- Routing Table Verification
- NAT Translation Verification
