# Linux Networking & Troubleshooting Command Reference

## 📌 Overview

This repository contains a practical Linux networking reference created for aspiring Network Operations Center (NOC) Analysts. It covers 30 essential Linux commands used for network configuration, connectivity testing, DNS troubleshooting, port analysis, service monitoring, and system diagnostics.

The guide includes command syntax, real-world use cases, expected output, verification steps, and screenshots.

---

## 🛠 Environment

- Kali Linux
- VMware / VirtualBox
- Bash Terminal

---

## 📚 Topics Covered

### Network Configuration

- ip addr
- ip link
- ip route
- hostname
- hostname -I

### Connectivity Testing

- ping
- traceroute
- tracepath
- mtr
- curl

### DNS Troubleshooting

- nslookup
- dig
- resolvectl
- cat /etc/resolv.conf
- getent hosts

### Ports & Connections

- ss
- netstat
- lsof
- nc
- telnet

### Network Information

- arp
- ip neigh
- ethtool
- tcpdump
- route

### System Troubleshooting

- systemctl
- journalctl
- ps
- top
- df
