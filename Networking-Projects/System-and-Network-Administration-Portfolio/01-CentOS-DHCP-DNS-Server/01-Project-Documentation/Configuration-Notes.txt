TROUBLESHOOTING NOTES
---------------------
1. If clients do not receive an IP address, check the DHCP service.
2. Check the DHCP logs using journalctl.
3. Verify that the client and server are connected to the same VMware VMnet1 network.
4. Verify that the server interface is configured with 192.168.10.2.
5. Check the DHCP configuration file for syntax errors.
6. Verify that the DHCP service is listening on UDP port 67.
7. If DNS resolution fails, check the named service.
8. Verify that clients use 192.168.10.2 as their DNS server.
9. Check the DNS zone files.
10. Validate DNS configuration using named-checkconf and named-checkzone.
11. Check that TCP and UDP port 53 are allowed through the firewall.
12. The virbr0 interface is part of the default libvirt networking environment and is separate from the project's VMnet1 network.
