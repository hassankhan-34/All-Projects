# Cisco Network Switching Lab

## 📌 Overview

This project demonstrates a complete Cisco switching environment using VLANs, VTP, IEEE 802.1Q Trunking, and Inter-VLAN Routing.

The lab is implemented on Cisco IOS switches and simulates an enterprise switching infrastructure with multiple VLANs and Layer 3 routing.

---

## 🛠 Technologies Used

- Cisco IOS
- EVE-NG
- VLANs
- VTP
- IEEE 802.1Q Trunking
- Layer 3 Switching
- Inter-VLAN Routing
