# 📝 TodoMaster - Simple Todo List App  
**A lightweight, responsive todo list application with local storage persistence.**  

✨ **Key Features**  
✔ **Task Management**  
- Add, edit, and delete tasks with ease  
- Mark tasks as complete with checkboxes  
- Persistent storage using `localStorage`  

🎨 **User Experience**  
- Clean, modern UI with responsive design  
- Empty state illustration for zero tasks  
- Keyboard-friendly (press `Enter` to add tasks)  

⚡ **Technical Highlights**  
- Vanilla JavaScript (no frameworks)  
- CSS variables for consistent theming  
- Mobile-optimized layout  

🚀 **How to Use**  
1. Type a task in the input field and click "Add Task" (or press `Enter`).  
2. Toggle the checkbox to mark tasks complete.  
3. Use the ✏️ (edit) and 🗑️ (delete) buttons to manage tasks.  

**About**  
TodoMaster helps you organize daily tasks with a minimalist interface. All data is saved locally in your browser—no signup or backend required!  

🔧 **Built With**  
- HTML5, CSS3, JavaScript  
- Font Awesome icons  
- CSS Flexbox for layout  

📌 **Note**  
This is a frontend-only project. Tasks are stored in `localStorage` and will persist until cleared manually.
