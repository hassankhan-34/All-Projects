# 🧮 Matrix Calculator (Python + NumPy)

A **command-line Matrix Calculator** built using **Python** and **NumPy**, designed to perform basic matrix operations interactively from the terminal.

---

## ✨ Features

- ➕ **Addition** of two matrices  
- ➖ **Subtraction** of two matrices  
- ✖️ **Multiplication** (Dot Product)  
- 🔁 **Transpose** of a matrix  
- 📐 Input custom matrix size and values  
- 💾 Uses **NumPy** for high-performance calculations  

---

## 📦 Technologies Used

- 🐍 **Python 3**  
- 🔢 **NumPy** for matrix operations  

---

## ✅ Ideal For

- 🧑‍💻 Beginners learning Python & NumPy  
- 🧠 Students studying matrices and linear algebra  
- 🔧 CLI-based math utility projects
