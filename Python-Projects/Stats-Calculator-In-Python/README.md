A command-line statistical analysis tool for educational and professional use.

## ✨ Key Features

### 🧮 Core Functionality
- **Central tendency calculations**: Mean, Median, Mode
- **Dispersion metrics**: Variance, Standard Deviation
- **Probability computation**: Basic event likelihood
- **Data validation**: Robust input handling

### 🔍 System Highlights
- **Interactive CLI interface** with menu navigation
- **Error-resistant design** with try-except blocks
- **Session persistence** for multiple calculations
- **Clean visualization** of statistical results

## 📈 Calculation Methods

**Statistical Relationships:**
- Mean → Sum of values / Count
- Median → Middle value in sorted list
- Mode → Most frequent value(s)
- Variance → Average of squared differences

**Design Principles:**
- Modular function architecture
- Input sanitization
- Graceful error recovery
- User-friendly output formatting
